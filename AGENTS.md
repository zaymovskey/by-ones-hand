# By One''s Hand — инструкции AI-агенту

## Текущий объём
Это только стартовый проект Phaser + TypeScript + Vite. Пустая сцена намеренна.
Не реализовывать бой, персонажей, AI, мир, квесты или другие игровые механики без отдельного запроса пользователя. Не переносить название Of Iron and Earth.

## Пользователь и обучение
Пользователь профессионально знает React и TypeScript, но новичок в геймдеве.
Объясняй новые игровые понятия простым языком: что это, зачем нужно, какие причины приводят к какому результату. Можно проводить аналогии с React, но поясняй ограничения аналогии: игровой цикл не является React-render.
Двигайся маленькими проверяемыми шагами. Перед изменением коротко объясни цель, после — что изменилось и как проверить. Не выдавай огромные куски кода без объяснений. Не вводи временные архитектурные костыли.

## Архитектурные границы
- src/simulation: обычный TypeScript. Никаких импортов Phaser, DOM, браузерных часов или графики. Здесь будущие правила и состояние.
- src/render: Phaser и визуальное представление. Считывает readonly snapshots, не меняет состояние симуляции.
- src/app: согласование времени и связь слоёв.
- src/main.ts: точка сборки зависимостей и жизненный цикл приложения.
- Будущий ввод передавать в симуляцию явными командами, а не чтением клавиатуры внутри правил.
- Не добавлять ECS, DI-фреймворк, event bus, физический движок или React без конкретной необходимости.
- Время симуляции измеряется в секундах; Phaser передаёт миллисекунды. Фиксированный шаг 1/60 секунды.
- У снимков нет изменяемых ссылок на внутреннее состояние; при расширении сохранять это свойство.

## Проверка
Запускай npm run build после изменений. Проверки поведения добавляй вместе с появлением реальных правил. Не заявляй о визуальной проверке, если она не проводилась.
